Privacy Policy — League Simulator Uploader

Last updated: 2026-11-05

What the app accesses

With the channel owner's consent, the app uses the YouTube Data API and YouTube Analytics API to: upload the owner's videos, post comments on the owner's videos, and read the owner's channel and video statistics.

How data is used and stored

OAuth tokens and statistics are stored only on the owner's own computer. Nothing is sent to any server other than Google's APIs. No data is sold, shared with third parties, or used for advertising.

The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. The app uses YouTube API Services; see the YouTube Terms of Service and the Google Privacy Policy.

Revoking access

Access can be revoked at any time at Google Account → Third-party connections. Deleting the local token files removes all stored data.

Contact

Use the user support email shown on the Google consent screen.
